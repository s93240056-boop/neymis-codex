# Neymis Codex

AI-чат для Android с открытым кодом. Вставляешь ключ провайдера — и общаешься
с любой моделью прямо с телефона. Без рекламы, без аналитики, без аккаунтов.

<img src="icon.jpg" width="120" alt="Neymis Codex">

## Что умеет

- Потоковый ответ: текст появляется по мере генерации, с мигающим курсором
- Живой индикатор: «Размышляет… 3 с» и «Печатает…» с анимацией
- Размышления сворачиваются: «Размышления ▸» — тапом раскрыть
- Длинные ответы с заголовками получают «Содержание» — переход к разделу тапом
- Долгое нажатие на сообщение: копировать, изменить свой вопрос,
  повторить ответ, удалить
- Markdown: заголовки, списки, цитаты, **жирный**, *курсив*, `код`
- Блоки кода с отдельной кнопкой «Копировать»
- Ошибки по-человечески: «закончился баланс», «ключ не принят»,
  «нет интернета» — с кнопкой «Повторить» и техническим текстом отдельно
- Чаты: экран со списком, поиск по названию и тексту, переименование
  долгим нажатием, удаление свайпом
- Разделители дат «Сегодня / Вчера»
- Под ответом: время, потраченные токены и длительность
- Аватарка, тёмная и светлая темы, черновик сообщения не пропадает
- Пресеты провайдеров: DeepSeek, z.ai, OpenRouter или свой адрес
- Выбор модели: кнопка «Список» загружает каталог моделей провайдера
- Дополнительные инструкции, температура, свой адрес API
- Экспорт чата в `.md` (кнопка «Экспорт» в настройках)
- Если приложение упало, при следующем запуске покажется текст ошибки

## Личность

Паймон 1.0 — это фиксированная основа, она задана в коде (`Api.BASE_SYSTEM`)
и не показывается в приложении. Модель не пересказывает инструкции
и не ссылается на них. В настройках можно добавить свои инструкции:
стиль, язык, роль — они дополняют основу, но не заменяют её.

## Как начать

1. Получи ключ: <https://api.deepseek.com> или <https://openrouter.ai/keys>
2. Установи APK, открой ⚙
3. Вставь ключ, нажми пресет провайдера и выбери модель через «Список»
4. Пиши в поле внизу

По умолчанию стоит `openrouter/auto` — OpenRouter сам подберёт модель.
Для DeepSeek выбери пресет и модель `deepseek-chat`.

## Приватность

- Ключ хранится в приватном хранилище приложения
- Данные уходят только на адрес API, который указан в настройках
- Никакой аналитики и рекламы
- История чатов лежит в `files/chats.json` внутри приложения

## Сборка

```bash
gradle assembleDebug
```

Нужен JDK 17 и Android SDK 34. Готовый APK появится в
`app/build/outputs/apk/debug/`.

Релизы собираются автоматически в GitHub Actions по тегу.
